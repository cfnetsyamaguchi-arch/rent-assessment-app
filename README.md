# 賃料査定書 自動入力アプリ

物件のマイソク（PDF）をアップロードすると、物件名・築年数・面積・間取・賃料・設備などを自動で読み取り、**賃料査定書（競合案件比較表）のExcel**として出力するツールです。

賃貸管理・オーナー提案の資料作成で、PDFを1件ずつ手入力していた作業をまとめて処理できます。

---

## 使い方（ブラウザ版）

公開URLを開くだけで、インストール不要で使えます。

1. 物件PDFをドラッグ＆ドロップ（複数まとめてOK）
2. 「PDFから抽出」を押す
3. 表示された表を確認・修正（設備の〇×はプルダウンで変更）
4. 「Excelをダウンロード」

既存の査定書Excelをアップロードすると、そのテンプレート（書式・レイアウト）を引き継いで下の行に追記します。

---

## 自動で読み取る項目

| 分類 | 項目 |
|---|---|
| 基本 | 物件名（号室含む）／築年数（和暦の記載でも**西暦に統一**）／専有面積／間取／住所 |
| 立地 | 最寄駅（複数記載時は徒歩分数が最短のもの）／徒歩分数／構造（RC・SRC・鉄骨・木造） |
| 条件 | 家賃／合計賃料（家賃＋管理費＋水道料金）／敷金／礼金／広告料（AD） |
| 設備 | EV／オートロック／室内洗濯機置場／脱衣所／浴室乾燥／追炊き／キッチン／シャンドレ／シューズBOX／宅配BOX／エアコン／ウォシュレット |

出力Excelには㎡単価の計算式（`=合計賃料/㎡数`）も自動で入ります。

### 敷金・礼金の扱い

「1ヶ月」「1.5ヵ月」のような月数表記は、**家賃（管理費・水道料金を含まない金額）を基準に**円へ換算します。合計賃料は基準にしません。

| PDFの記載 | 家賃60,000円のときの出力 |
|---|---|
| 1ヶ月 | 60,000 |
| 1.5ヶ月 | 90,000 |
| 50,000円 | 50,000 |
| 5万 | 50,000 |
| なし／0円／- | 0 |

換算の基準が正しいか確認できるよう、画面の表には「家賃」列を表示しています（この列はExcelには出力されません）。家賃が読み取れなかった場合は換算せず、PDFの原文をそのまま表示します。

敷金・礼金・家賃・合計賃料・徒歩・㎡数は数値として出力されるので、Excel側でそのまま並べ替え・計算できます。

> **注意:** 画像としてスキャンされたPDFは文字情報を持たないため自動抽出できません。その場合は表に直接入力してください。

## 手元のPCで動かす場合

```bash
git clone https://github.com/<ユーザー名>/<リポジトリ名>.git
cd <リポジトリ名>
pip install -r requirements.txt
streamlit run app.py
```

ブラウザで `http://localhost:8501` が開きます。Python 3.9 以上が必要です。

---

## 技術構成

- [Streamlit](https://streamlit.io/) — UI
- [pdfplumber](https://github.com/jsvine/pdfplumber) — PDFのテキスト抽出
- [openpyxl](https://openpyxl.readthedocs.io/) — Excel生成

抽出ロジックは `app.py` の `parse_pdf()` にまとまっています。取り扱うマイソクの書式に合わせて正規表現を追記すれば精度を上げられます。

## プライバシー

アップロードしたPDFはその場で処理されるだけで、サーバーに保存されません。ブラウザを閉じるとデータは消えます。
