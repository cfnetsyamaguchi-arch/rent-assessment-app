# 賃料査定書 自動入力アプリ

物件のマイソク（PDF）をアップロードすると、**様式がバラバラでも・画像PDFでも**、物件名・築年数・面積・間取・賃料・設備などを自動で読み取り、**賃料査定書（競合案件比較表）のExcel**として出力するツールです。

賃貸管理・オーナー提案の資料作成で、PDFを1件ずつ手入力していた作業をまとめて処理できます。

---

## 使い方（ブラウザ版）

公開URLを開くだけで、インストール不要で使えます。

1. 物件PDFをドラッグ＆ドロップ（複数まとめてOK）
2. 「PDFから読み取り」を押す
3. 表示された表を確認・修正（「要確認」欄に注意点が出ます。設備の〇／×／未確認はプルダウンで変更）
4. 「Excelをダウンロード」

既存の査定書Excelをアップロードすると、「物件名」「合計賃料」などの見出しがあるシート（競合案件シート）を自動で探し、**見出しの名前で列を合わせて**、最後の行の次に同じ書式で追記します。表紙・スタッキングなど他のシートには触れません。

見積書・請求書など物件資料でないPDFは自動で除外します。

---

## 自動で読み取る項目

| 分類 | 項目 |
|---|---|
| 基本 | 物件名（号室含む）／築年数（和暦の記載でも**西暦の年月に統一**：平成3年3月 → 1991年3月）／専有面積／間取／住所 |
| 立地 | 最寄駅（複数記載時は徒歩分数が最短のもの）／徒歩分数／構造（RC・SRC・鉄骨・木造） |
| 条件 | 家賃／合計賃料（家賃＋管理費＋水道料金）／敷金／礼金／広告料（AD） |
| 設備 | セパ（バス・トイレ別）／EV／オートロック／洗面台／室内洗濯機置場／脱衣所／キッチン（システム・口数・ガス/IH）／収納（CL・WIC・SB）／シャンドレ／ウォシュレット／浴室乾燥／追炊き／宅配BOX／エアコン |
| 特筆事項 | 賃料＋共益費の内訳／ネット無料／家具家電付／ペット可否／定借／クリーニング費用 |

出力Excelには㎡単価の計算式（`=合計賃料/㎡数`）も自動で入ります。

### 敷金・礼金の扱い

「1ヶ月」「1.5ヵ月」のような月数表記は、**家賃（管理費・水道料金を含まない金額）を基準に**円へ換算します。合計賃料は基準にしません。

| PDFの記載 | 家賃60,000円のときの出力 |
|---|---|
| 1ヶ月 | 60,000 |
| 1.5ヶ月 | 90,000 |
| 50,000円 | 50,000 |
| 5万 | 50,000 |
| なし／0円／- | 0 |

換算の基準が正しいか確認できるよう、画面の表には「家賃」列を表示しています（この列はExcelには出力されません）。家賃が読み取れなかった場合は換算せず、PDFの原文をそのまま表示します。

敷金・礼金・家賃・合計賃料・徒歩・㎡数は数値として出力されるので、Excel側でそのまま並べ替え・計算できます。

### 画像PDF（スキャン・画像で作られたマイソク）

文字認識（OCR・Tesseract日本語）で読み取ります。1枚あたり30秒ほどかかります。

OCRは「10,000」を「10.000」と読むなどの誤読があるため、桁区切りの補正や、同じページを3通りの方式で読んで多数決をとる工夫をしています。それでも誤読はありうるので：

- OCRで読んだ行には「要確認」を表示します
- 資料に見つからなかった設備は × ではなく「未確認」にします
- 礼金が家賃の6ヶ月を超えるなど、不自然な値は「要確認」に理由を出します

## 手元のPCで動かす場合

```bash
git clone https://github.com/<ユーザー名>/<リポジトリ名>.git
cd <リポジトリ名>
pip install -r requirements.txt
# 画像PDFを読むには Tesseract（日本語）も必要
#   Mac: brew install tesseract tesseract-lang
#   Windows: https://github.com/UB-Mannheim/tesseract/wiki
streamlit run app.py
```

ブラウザで `http://localhost:8501` が開きます。Python 3.9 以上が必要です。

## 技術構成

- [Streamlit](https://streamlit.io/) — UI
- [pdfplumber](https://github.com/jsvine/pdfplumber) — PDFのテキスト抽出
- [Tesseract OCR](https://github.com/tesseract-ocr/tesseract) + pytesseract — 画像PDFの文字認識（Streamlit Cloudでは `packages.txt` で導入）
- [openpyxl](https://openpyxl.readthedocs.io/) — Excel生成

読み取りは `extractor.py`、Excel書き出しは `excel_writer.py`、画面は `app.py` です。抽出ロジックは `extractor.py` の `parse_pdf()` にまとまっています。取り扱うマイソクの書式に合わせて正規表現を追記すれば精度を上げられます。

## プライバシー

アップロードしたPDFはその場で処理されるだけで、サーバーに保存されません。ブラウザを閉じるとデータは消えます。
